## 🪄 Tentang Proyek
> “Langkah kecil bikin halaman web, masa depan jadi besar.”  

Repositori ini berisi **materi dan contoh proyek HTML dasar** untuk siswa **SMK Muhammadiyah 3 Tangerang Selatan**.  
Kamu akan belajar membuat halaman web sederhana, mengenal tag-tag HTML, dan memahami struktur dokumen web.

---

## 🎨 Fitur & Materi

| Materi | Deskripsi |
|:-------|:-----------|
| 🏗️ Struktur HTML | Mengenal `<html>`, `<head>`, `<body>` |
| ✍️ Teks & Paragraf | Menggunakan `<h1>`–`<h6>`, `<p>`, `<br>` |
| 🔗 Link & Gambar | `<a>`, `<img>` untuk navigasi & media |
| 📊 Tabel | `<table>`, `<tr>`, `<th>`, `<td>` |
| 🧩 Layout | Mengatur elemen dengan `<div>` dan `<span>` |
| 💡 Tambahan | Form, list, dan meta tag |
